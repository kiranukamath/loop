# Job Description — Senior Backend Engineer

**Company:** FinTech Startup (Series B)
**Role:** Senior Backend Engineer — Payments Platform
**Location:** Remote (US timezones)

## About the role

We're building the next-generation payments infrastructure.  You'll design and own
high-throughput services that process millions of transactions a day.

## Responsibilities

- Design and build distributed microservices on AWS (ECS, SQS, RDS, ElastiCache).
- Own the payments processing domain end-to-end: API contracts, async event flows, retries,
  idempotency, reconciliation.
- Conduct and receive technical design reviews; mentor junior engineers.
- Drive observability: structured logging, metrics, distributed tracing.
- Partner with Product and Infra on capacity planning and SLA commitments.

## Requirements

- 5+ years of backend engineering experience.
- Deep expertise in Java (Spring Boot preferred) or a JVM language.
- Strong grasp of distributed systems: consistency models, failure modes, backpressure.
- Experience with event-driven architecture (Kafka or SQS).
- Hands-on AWS: IAM, VPC, ECS/EKS, RDS/Aurora, CloudWatch.
- Comfortable with SQL (Postgres) and at least one caching layer (Redis/ElastiCache).
- Strong communication — you write clear design docs and can explain tradeoffs.

## Nice to have

- Experience with payment rails (ACH, card networks, ISO 20022).
- Exposure to high-stakes consistency patterns (sagas, outbox pattern).
- Previous fintech or regulated-industry experience.
