Loop
Agentic Interview Coach

An AI agent that builds a personalised prep plan, runs mock interviews across coding, system design, and behavioural domains, grades answers in real time, and delivers a human-approved readiness verdict — all with durable state across sessions.

View on GitHub → See how it works
📋

Personalised plan

Reads your job description and profile, identifies key gaps, and generates a multi-session prep curriculum.

🎤

Live mock interviews

Poses real questions across coding, system design, and behavioural domains. Grades your answer against a detailed rubric.

🎯

Readiness verdict

Synthesises session feedback into a human-approved ready / not-ready verdict with confidence score and recommended next steps.

Why it was built

Five agentic AI capabilities, one phase each

Loop exists to exercise these patterns in a real, runnable system — not toy examples.

P2

Planning

Structured output

The planner node calls an LLM with .with_structured_output(PrepPlan) — Pydantic schema enforces the output shape. It also reads stored weak areas from prior sessions and folds them into the prompt before generating the next plan.

P3

Orchestration

Sub-agents · routing · loops

A conditional edge after session_router dispatches to one of three specialist interviewer nodes (coding / system-design / behavioural). An advance_session node increments the session index and a loop-back edge routes to the next session or to readiness — a directed cycle in the LangGraph.

P4

Memory

Short-term · long-term

Short-term: SqliteSaver checkpoints full graph state after every node — interrupts are resumable and process restarts are transparent. Long-term: InMemoryStore (keyed by user_id) persists weak areas across independent sessions, enabling the planner to adapt its next curriculum.

P5

HITL (Human-in-the-Loop)

interrupt() · Command(resume)

Three approval gates: plan_approval (approve / edit / reject the PrepPlan), the interviewer answer gate (type your response), and readiness (approve or override the verdict). Each gate calls interrupt(payload) to serialise to the checkpoint and pause the graph until Command(resume=...) is sent.

P6

Eval

Output quality · trajectory

A human-labeled dataset of 9 answer→grade pairs (strong / medium / weak across all modalities) drives a Langfuse experiment. Two complementary dimensions: output quality (did the grader score correctly?) and trajectory (did the agent visit nodes in the right order?). A wrong path can produce a right answer — both checks are needed.

Quick start
# clone and install
git clone https://github.com/kiranukamath/loop.git && cd loop
cp .env.example .env          # fill in AWS + Bedrock creds
uv sync

# run tests (offline, no model calls)
uv run pytest

# start the web UI
uv run uvicorn loop.api:app --port 8000 --reload
open http://localhost:8000
